# FPC Warehouse Intelligence — عرض تقديمي

عرض تقديمي تفاعلي (HTML واحد بدون اعتماديات) يشرح نظام مساعد المخزون الذكي على واتساب لشركة FPC: الأسئلة الفورية عن المخزون، التقرير اليومي، التنبيهات التلقائية، وتوقعات تقادم اللفات.

العرض متوفر بأربع لغات (عربي، English، Français، Português) ويُبدَّل بينها من الشريط العلوي دون إعادة تحميل الصفحة.

## التشغيل

لا يحتاج إلى أي تثبيت: افتح `index.html` في المتصفح مباشرة، أو شغّل خادماً ثابتاً:

```bash
python3 -m http.server 8080
```

### التنقل

| الإجراء              | الطريقة                         |
| -------------------- | ------------------------------- |
| الشريحة التالية/السابقة | مفاتيح الأسهم ← → أو أزرار الأسفل |
| أول/آخر شريحة        | Home / End                      |
| على الجوال           | السحب يميناً أو يساراً           |
| تغيير اللغة          | الأزرار في أعلى الصفحة           |

اتجاه الأسهم يتبع اتجاه اللغة المختارة (RTL للعربية).

## البنية

- `index.html` — العرض الكامل: الأنماط، البيانات، ومنطق العرض في ملف واحد.
- `AI_Warehouse_Presentation_AR.html` — نسخة مطابقة تحمل الاسم الأصلي للملف المُرسَل.

المحتوى مُعرَّف في الكائن `T` داخل `<script>`: لكل لغة مصفوفة `slides` تحتوي شرائح من أنواع مختلفة (`title`, `cards2`, `aging`, `risks`, `alerts`, `chat`, …) ويقوم `renderSlide()` بتحويل كل نوع إلى HTML. لإضافة شريحة جديدة أضف عنصراً إلى المصفوفة بنفس البنية في كل لغة.

الخطوط (Tajawal, Outfit, IBM Plex Mono) تُحمَّل من Google Fonts، وهي الاعتمادية الخارجية الوحيدة.
